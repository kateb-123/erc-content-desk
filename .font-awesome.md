# Font Awesome Configuration

Detected by the Font Awesome agent tools. Commit this file so the whole team benefits.

## Integration

- **Method:** Web Fonts + CSS via CDN (cdnjs), class-based `<i>` elements
- **Version:** 7.3.1
- **License:** Free
- **CDN URL:** https://cdnjs.cloudflare.com/ajax/libs/font-awesome/7.3.1/css/all.min.css
- **Families:** classic

## Defaults

- **Style:** solid
- **Family:** classic

## Import Pattern

- No build step — the stylesheet is linked from `index.html`.
- Icons are created in JS as `<i class="fa-solid fa-{name}" aria-hidden="true">` via helpers in `js/icons.js` (see `forwardIcon()`).

## Conventions

- The desk otherwise draws its own inline SVGs (`checkSvg`, the dots loader) — Font Awesome is for small glyph accents like the header door-button arrows, not for replacing those.
- No emojis anywhere in desk UI copy (standing rule); icons are the sanctioned decoration.
- Icon elements always carry `aria-hidden="true"` — the button text carries the meaning.
