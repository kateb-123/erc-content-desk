Add content

Add one item

  1. Paste the item's link.
  2. Pick a type, then its subtype. Which type says what each is.
  3. Put the date, time and place, or the deadline, in the Description.
  4. Add your initials, then click Add to the queue.

Claude then reads the link and fills in what you left blank. The more you fill in, the better it does.

Bulk add items

For a list from a scraper, a newsletter or your notes. The spreadsheet is best: its columns are the desk's own, so nothing is guessed. A Word file goes through Claude, which splits it into items.

  1. Download the spreadsheet template, or the Word template.
  2. Fill it in, one item per row. Or give an AI your list and the template, and have it fill the template. Every item needs a link.
  3. Drop the file on Add a doc or spreadsheet, under the form.
  4. Check the list it shows, then click Add to the queue. The button counts the items.

Claude then reads each item's link, as it does for one.
