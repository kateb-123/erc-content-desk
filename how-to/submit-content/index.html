Add content

Add one item

  1. Paste the item's link.
  2. Pick a type and a subtype (see Item types).
  3. Put the date, time and place, or the deadline, in the Description.
  4. Add your initials, then click Add to the queue.

Claude reads the link and fills in what you left blank. The more you fill in, the better it does.

Bulk add items

For a list from a scraper, a newsletter or your notes. Use the spreadsheet: it maps straight into the desk.

  1. Download the spreadsheet template (or the Word one).
  2. One item per row. Every item needs a link. An AI can fill it from your list.
  3. Drop it on Add a doc or spreadsheet.
  4. Check the list, then Add to the queue.

Claude then reads each link.

Everything is reviewed before it goes out.
