Build the newsletter

From what was kept to what goes out, on Next issue and in the builder.

Open Newsletter

Where items come from

Next issue

  1. Kept items wait in Ready to add.
  2. Add puts one in the issue. Quick add puts in something new.
  3. The builder only pulls what is in the issue.

Build the issue

Review

  1. Open the builder from Next issue.
  2. Pick the issue, then Pull from the desk.
  3. Pull again any time. Only new items come in.

Outline

  1. Put items in order with the arrows.
  2. Mark one event Featured.
  3. Remove takes an item out. Undo puts it back.

Preview & Tweak

  1. Fix titles, dates, the introduction and pictures.

Every fix in Preview & Tweak, never in Outlook, so the archive matches what went out.

Send and archive

Save & Export

  1. Copy HTML, paste it into Outlook, send.
  2. Save to the archive. It shows under Past issues.
