How to change the Policy Exchange

Add, fix, remove, highlight, and the look.

What the site is

Two public files in its GitHub repo: data/news.csv, one line per item, and data/featured.json, what the New & Upcoming card shows and what is hidden.

The desk's Publish adds lines to the first and sets the card's pins in the second. The site's edit door changes both.

Add items

  1. On Content Sort, leave ERC Newsletter only unticked. Ticked, the item never reaches the site; an A&M event comes ticked. Press Keep and next.
  2. Open Policy Exchange, then Publish.
  3. Press Publish N to the Exchange, type the desk password, press Confirm.

Fix a live item

Publish only adds lines, so a desk edit to a live item stays on the desk. Fix it on the edit door, on a laptop:

  1. On the Policy Exchange hub, open Edit live items. Sign in with the Exchange's own password, not the desk's.
  2. Press Edit on the item, fix it, press Save.

Remove a live item

The desk's Delete never touches the site. On the edit door, press Edit, then:

  • Hide from the site: off the pages, still in the public news.csv. Show again is under Hidden items in the top strip.
  • Delete…, then Delete it: the line goes. Undo lasts only while its note shows.

Past events, closed opportunities and headlines over 60 days old leave by themselves.

Change the highlight

The big card on the home page has its own page: Policy Exchange, then Highlight. It works any day, with or without anything to publish.

  1. In Pick from, press Highlight on a row. Set its photo and its Until day.
  2. Press Update the highlight, type the desk password, press Confirm.

Publishing never changes the card. An event or opportunity pick gets card words; the card shows them, and the photo, in place of the item's own.

A Drive picture link never shows on the card; use one ending .jpg, .png or .webp.

An announcement card is Add to New & Upcoming, in the edit door's top strip.

Change a logo or the look

It is code in the Exchange's GitHub repo: open it in Claude Code and say what to change. A push to main is live in a minute.
