Publish

Open Policy Exchange from the desk's front page.

1Waiting to publish: what Publish would add now. An item reaches the site only if ERC Newsletter only stays unticked. An A&M campus event comes ticked.

2Publish: the page that sends the waiting items to the site.

3Highlight: the big card on the site's home page.

4Edit live items: the site's own door to fix, hide or delete a live item.

Only the Adding rows go to the site.

1Check them on Finalize: read each rewrite before it goes out.

2A color: click it to show only those rows.

3Fate: Adding, Held for newsletter, Needs a fix or Already live. A row that needs a fix names what is missing. Click those words to fix it in place.

4Publish N to the Exchange: asks for the password next.

Press Publish N to the Exchange, type the desk password, and press Confirm.

1Password: the desk password, the one Content Sort asks for. It is in READ ME FIRST - ERC handoff, in the shared drive.

2Confirm: adds the rows to the live site.

3Cancel: nothing is sent.

→Each publish files a copy of the site's list in the shared drive, in ERC Content Desk, Policy Exchange.

Highlight

Open Highlight on the Policy Exchange page. It works any day, and publishing never changes the card.

1On the site now: what the big card shows this minute. Cards made on the edit door with Add to New & Upcoming show here too, after the picks.

2Add photo or Replace photo: a picture file from your computer. A Drive picture link never shows on the card. If the item has one, press Replace photo and choose a file.

3Until: the last day the pick stays on the card.

4Write the card: the card's own words for an event or opportunity. An event or opportunity pick gets card words. The card shows them, and the photo, in place of the item's own.

In Pick from, press Highlight on a row, then give it a photo above. A blank Until becomes the event's date or the deadline, else two weeks.

1Search: by title or source, every live item.

2A section: show only its items.

3Highlight: adds it to Your picks.

4In, 2nd: already picked, and its place on the card.

Press Update the highlight, type the desk password, and press Confirm.

1Update the highlight: asks for the password, then Confirm.

2Cancel changes: back to what the site shows now.

Fix or remove a live item

Publish only adds lines, so a desk edit to a live item stays on the desk. Fix the site on its own edit door, on a laptop.

!It asks the team password, the same as the desk's. It is in READ ME FIRST - ERC handoff, in the shared drive.

Fix a live item

  1. On the Policy Exchange page, open Edit live items. The site's sign-in opens in a new tab.
  2. Type the team password and press Sign in.
  3. Press Edit on the item, fix it, and press Save.

The desk's Delete never touches the site. On the edit door, press Edit on the item, then hide it or delete it.

→Past events, closed opportunities and headlines over 60 days old leave by themselves.

Hide it

  1. Hide from the site takes it off the pages. It stays in the public news.csv.
  2. Hidden items, in the top strip, lists it with Show again.

Delete it

  1. Press Delete…, then Delete it.
  2. Undo works only while its note shows.

Change the look

Logos, words and section names are code in the Exchange's GitHub repo. Open it in Claude Code and say what to change. A push to main is live in a minute.
