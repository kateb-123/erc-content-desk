Bring back the Google scripts

Two scripts, 15 minutes, any time.

Two Google scripts run inside two Sheets in the shared drive, under the login that set them up. When that account closes they stop until someone redeploys them. Nothing is lost.

SheetWhereWhat stops
erc-content-deskERC Content Desk, Content queueThe queue's Sheet copy, the scraper's files, the briefs' folders
subscribe to listserveERC Content Desk, ListservListserv sign-ups

For each Sheet

  1. Open it, then Extensions, Apps Script.
  2. Deploy, New deployment. Pick Web app from the gear.
  3. Execute as: Me. Who has access: Anyone. Deploy.
  4. Allow the permissions. If Google says unverified, choose Advanced, then Go to the project.
  5. Copy the Web app URL, ending in /exec, and email it to the desk's owner (the handoff document has the address). Say which Sheet.

Check it

  • Queue: a test item on the team form shows up in the Sheet within a minute. Delete it on Content Sort.
  • Listserv: the Listserv page shows a number, not a warning.

If it goes wrong

  • "Unknown action" or a 500: send the newest Web app URL again.
  • No Extensions menu: you need edit access to the Sheet.
  • Leave the script's settings (Script properties) alone.
