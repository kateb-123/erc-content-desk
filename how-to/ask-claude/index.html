ERC Content Desk / How-tos

Ask Claude about the desk

Questions about the desk, answered from its how-tos.

Claude can answer questions about the desk from its how-tos. Set it up once, then ask in plain words.

Set it up once

  1. On claude.ai, open Projects, then Create project. Name it "ERC Content Desk help".
  2. Download the desk guide, every how-to in one file. In the project, add it under Project knowledge.
  3. In the project's instructions, paste: Answer questions about the ERC Content Desk from the guide in this project. Name the page and the button. If the guide does not say, say so.

Ask

Start a chat inside the project and ask, for example: "How do I take an item out of the next issue?" or "Why didn't my item reach the Policy Exchange?"

No project? Start any chat, attach the desk guide, and ask.

Keep it current

When a how-to changes, download the guide again and replace the file in the project.

Never

Never paste a password into Claude. If Claude cannot answer, use Report a problem, in the corner of every desk page.
